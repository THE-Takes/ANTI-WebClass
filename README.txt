1. 概要
================================================================================

ANTI-WebClassは、神奈川大学のWebClass学習管理システムのユーザー体験を
大幅に改善するChrome拡張機能です。

主な改善点：
  * ホーム画面に全コースの課題を一覧表示
  * 未読メッセージの一括確認・既読化
  * ダウンロードファイルの自動リネーム
  * Microsoft To Doとの課題同期


================================================================================
2. 機能一覧
================================================================================

+---------------------------+----------------------------+------------+
| 機能名                    | 説明                       | 設定が必要 |
+---------------------------+----------------------------+------------+
| スマートToDoリスト        | 全コースの課題を一覧表示   | 不要       |

+---------------------------+----------------------------+------------+

--------------------------------------------------------------------------------
3.1 スマートToDoリスト
--------------------------------------------------------------------------------

【概要】
WebClassのホームページ右側に、全コースの課題を自動収集して表示します。

【機能】
  * 課題を期限順に自動ソート
  * 緊急度による色分け表示
    - 赤色背景：期限まで48時間以内
    - 黄色背景：期限まで1週間以内
    - 白色背景：1週間以上余裕あり
  
  * 課題の分類表示
    - 通常の課題：常に展開表示
    - 1カ月以上先の課題：折りたたみ（クリックで展開）
    - 期限なしの課題：折りたたみ（クリックで展開）
    - 完了済みの課題：折りたたみ（クリックで展開）

  * 課題のチェック機能
    - チェックボックスで完了/未完了を切り替え
    - 完了状態はブラウザに保存され、次回アクセス時も維持

  * 課題タイトル・期限の編集
    - タイトル部分をクリックして直接編集可能
    - 期限は日付ピッカーと時刻ピッカーで変更可能

【使い方】
  1. WebClassのホームページにアクセス
  2. 画面右側の「スマートToDoリスト」カードを確認
  3. 「課題を更新 (全コース取得)」ボタンをクリック
     -> 全コースの課題が自動取得されます（初回は数十秒かかります）

【設定】
  特に設定は不要です。自動的に動作します。


--------------------------------------------------------------------------------
3.2 メッセージウィンドウ
--------------------------------------------------------------------------------

【概要】
ホームページに未読メッセージを表示し、一括で既読にできます。

【機能】
  * 未読メッセージ一覧の表示
  * 未読件数バッジの表示
  * 「全て既読にする」ボタンで一括既読化
  * メッセージをクリックで詳細表示

【使い方】
  1. WebClassのホームページにアクセス
  2. 画面右側の「メッセージ」カードを確認
  3. 未読メッセージがあれば黄色背景で表示
  4. 「全て既読にする」ボタンで一括既読化
  5. 既読にしたメッセージは緑色背景で表示

【設定】
  特に設定は不要です。自動的に動作します。


--------------------------------------------------------------------------------
3.3 ダウンロード機能強化
--------------------------------------------------------------------------------

【概要】
資料や課題ファイルのダウンロード時に、分かりやすいファイル名を付けます。

【機能】
  * リネームしてダウンロード
    - 課題名をファイル名として保存
    - 例：「レポート課題.pdf」

  * 元のファイル名でダウンロード
    - サーバー上の元のファイル名で保存
    - 例：「kadai_20251127.pdf」

  * 画像として保存（PDFのみ）
    - PDFの各ページをPNG画像として保存
    - 複数ページの場合は連番付き

【使い方】
  1. 資料や課題のページを開く
  2. ダウンロードリンクをクリック
  3. ダウンロードウィンドウで選択：
     - 「リネームしてダウンロード」
     - 「元のファイル名でダウンロード」
     - 「画像として保存」（PDFの場合）

【PDFビューアでの使い方】
  PDFビューア（loadit.php）では、ツールバーに追加ボタンが表示されます：
  - ダウンロードボタン：リネームしてダウンロード
  - 画像ボタン：全ページを画像として保存

【設定】
  特に設定は不要です。自動的に動作します。


--------------------------------------------------------------------------------
3.4 自動ログイン
--------------------------------------------------------------------------------

【概要】
WebClassログインページで、ユーザー名とパスワードを自動入力します。

【!! 重要な警告 !!】
  ======================================================================
  ユーザー名とパスワードはブラウザ内に保存されます。
  暗号化は簡易的なものであり、完全に安全ではありません。

  【絶対に避けるべきこと】
    [NG] 共用PCでの使用
    [NG] 公共の場所（図書館、ネットカフェ等）での使用
    [NG] 他人がアクセスできるPCでの使用
  ======================================================================

【設定方法】
  1. 拡張機能の設定画面を開く（後述）
  2. 「高度な設定」セクションを確認
  3. 「自動ログインを有効にする」にチェック
  4. ユーザーIDとパスワードを入力
  5. 「保存」ボタンをクリック

【使い方】
  設定後、ログインページにアクセスすると自動的にログインされます。


--------------------------------------------------------------------------------
3.5 Microsoft To Do 連携（実験的機能）
--------------------------------------------------------------------------------

【概要】
WebClassの課題をMicrosoft To Doアプリに自動同期します。
iPhoneやAndroidのTo Doアプリで課題を管理できるようになります。

【前提条件】
  * Microsoftアカウントが必要です
  * Azure ADでアプリ登録が必要です（開発者向け）

【機能】
  * 課題の自動同期
    - 課題タイトル、期限、コース名が同期されます
    - 新しい課題が追加されると自動で同期

  * 双方向完了状態同期
    - WebClassで完了にした課題 -> To Doでも完了
    - To Doで完了にした課題 -> WebClassでも完了

  * リマインダー設定
    - 通知タイミング：1日前〜7日前から選択
    - 通知時刻：「ちょうど（同時刻）」または「朝9時」

【設定方法】
  1. 拡張機能の設定画面を開く
  2. 「Microsoft To Do 連携」セクションを確認
  3. 「Microsoft To Do 設定を開く」ボタンをクリック
  4. 専用の設定ページで：
     a. クライアントIDを入力（Azure ADで取得）
     b. 「Microsoftでサインイン」をクリック
     c. 同期先のリストを選択
  5. メイン設定画面でリマインダー設定を調整
  6. 「保存」ボタンをクリック

【リマインダー設定】
  +--------------------+-------------------------------------+
  | 設定項目           | 選択肢                              |
  +--------------------+-------------------------------------+
  | 通知タイミング     | 通知しない / 1日前〜7日前           |
  | 通知時刻           | ちょうど（同時刻）/ 朝9時           |
  +--------------------+-------------------------------------+

  例：期限が「2025/12/1 17:00」の課題の場合
    - 「1日前 + 朝9時」-> 2025/11/30 9:00 にリマインダー
    - 「2日前 + ちょうど」-> 2025/11/29 17:00 にリマインダー

【同期データのリセット】
  問題が発生した場合は「同期データをリセット」ボタンで：
    * スマートToDoの完了状態をリセット
    * 次回同期時に全ての課題が再同期されます
  ※ Microsoft To Do側のタスクは削除されません


================================================================================
4. 設定画面へのアクセス方法
================================================================================

【方法1：拡張機能アイコンから】
  1. ブラウザ右上の拡張機能アイコン（パズルのピース）をクリック
  2. 「ANTI-WebClass」を探してクリック
  3. 設定画面がポップアップで表示されます

【方法2：拡張機能の管理画面から】
  1. ブラウザで chrome://extensions を開く
  2. 「ANTI-WebClass」を探す
  3. 「詳細」をクリック
  4. 「拡張機能のオプション」をクリック


================================================================================
5. トラブルシューティング
================================================================================

【課題が取得できない】
  * ページを再読み込みして「課題を更新」ボタンを再度クリック
  * WebClassにログインしているか確認
  * しばらく待ってから再試行（サーバーが混雑している可能性）

【Microsoft To Do同期が動作しない】
  * 設定画面で接続状態を確認
  * 「同期データをリセット」を試す
  * 再度Microsoftでサインインし直す

【ダウンロードボタンが表示されない】
  * ページを再読み込み
  * ダウンロードウィンドウ（file_down.php）が開いているか確認

【自動ログインが動作しない】
  * 設定画面で「自動ログインを有効にする」がチェックされているか確認
  * ユーザーIDとパスワードが正しく入力されているか確認
