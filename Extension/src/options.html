ホーム

デフォルトビュー

ホームページを開いたときに使用するビューを選択してください。

ショートカット: 表示モード切替

1つのショートカットで、画面改変OFF（Plain）と画面改変ON（Switch View 2）を切り替えます。WindowsではAlt、MacではOptionとして使えます。空欄で無効化できます。

ホーム表示項目: 時間割の表示範囲

6x6 のボックスで、開始セルまたは終了セルをドラッグしてホーム時間割に表示する範囲を調整します。

ホーム表示項目: ToDo 強調

My TODOs で赤く表示される期限間近のタスクがある講義だけ、時間割マスに薄い赤のアウトラインを表示します。

右上のユーザーアイコン

JPG、PNG、WebPなどの画像を選択できます。

GitHub Release 通知

GitHub Releases の最新安定版を確認します。更新通知のみ行い、zip などのダウンロードは行いません。

デバッグ用です。実際の更新有無に関係なく、更新通知の表示だけを確認します。

コース

左ジャンプリンクの初期表示

コースページ左側の各コースへのジャンプリンクを、ページを開いたときに展開するかを選択します。

ToDo API 連携

Smart ToDo と外部ToDoサービスを同期します。

一度に1つのサービスと同期します。切り替え・接続解除でも既存の外部タスクは残ります。

初期設定はOFFです。ONにすると開始前の課題も連携します。外部ToDoの期限には通常の締切日時だけを使い、開始日時は期限として連携しません。

Appleリマインダー設定

macOS 14以降のChromeと、WebClass Reminders補助アプリが必要です。専用リスト「WebClass」と課題名・締切・完了状態を同期します。

補助アプリの導入手順

同期にはブラウザーの起動が必要です。新しい課題の取得には、従来どおりログイン済みのWebClassホーム画面を使用します。

TickTick 設定

TickTick Developer Console ↗

Client Secret はローカルに暗号化して保存されます。

この URI を TickTick Developer ページの「Oauth redirect URL」に設定してください。

連携タスク名の形式

形式3を選択した場合に使用する、コースごとの超短縮名です。
