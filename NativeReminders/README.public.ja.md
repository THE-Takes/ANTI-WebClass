# WebClass Reminders の導入

WebClassの課題をAppleリマインダーと同期するmacOS用の補助アプリです。macOS 14以降とGoogle ChromeまたはDiaが必要です。補助アプリはどちらか1つのブラウザーにだけ登録します。v0.3.1のインストーラーZIPは[最新リリース](https://github.com/THE-Takes/ANTI-WebClass/releases/latest)から入手できます。公開ソースから自分のMacでビルドする場合は[ビルド手順](BUILD_FROM_SOURCE.ja.md)を参照してください。ANTI-WebClass拡張機能本体は別途インストールしてください。

## インストール

1. 使うブラウザーをGoogle ChromeかDiaから1つ選びます。Chromeでは `chrome://extensions`、Diaでは `dia://extensions` を開き、ANTI-WebClassの拡張機能IDをコピーします。
2. ビルド手順で生成された「Install WebClass Reminders」を起動します。
3. インストーラーで同じブラウザーを1つ選び、拡張機能IDを貼り付けて「インストール」を押します。以前のブラウザー登録があれば置き換えます。
4. 選んだブラウザーのANTI-WebClass設定で外部ToDo連携を有効にし、連携先にAppleリマインダーを選びます。
5. 「Appleリマインダーに接続」を押し、選んだブラウザーとmacOSに表示されるアクセス要求を許可します。
6. ログイン済みのWebClassホーム画面から、通常のToDo同期を実行します。

同期中はインストールや更新を行わず、先に同期を止めてください。拡張機能IDは選択したブラウザーの接続設定にだけ保存され、WebClassや外部サーバーには送信されません。別のブラウザーを選び直すと、前のブラウザーの登録は解除されます。

## 同期される内容

専用の「WebClass」リストにある、ANTI-WebClassが管理する課題だけが同期対象です。課題名、締切、完了状態と課題リンクを反映します。管理対象を示す `WC_SYNC_ID` は削除しないでください。対象課題を同期から外す場合は、WebClass側のゴミ箱を使います。

課題の元情報や同期の復旧に必要なメタデータはこのMacに保存されます。設定とメタデータのバックアップ方法は[詳細手順](README.ja.md)を参照してください。AppleリマインダーのアカウントをiCloudで使っている場合、Appleの通常の同期によってほかの端末にも変更が反映されます。

## アンインストール

展開した「Install WebClass Reminders」をもう一度開き、「アンインストール」を押します。補助アプリとChrome・Diaにあるこの連携の登録を削除します。Appleリマインダーのリスト・課題とMac側の同期メタデータは削除されません。

## うまくいかない場合

- 接続できない場合は、インストーラーで選んだブラウザーと拡張機能IDが一致していることを確認します。同時に使えるブラウザーは1つです。
- アクセス要求を閉じてしまった場合は、macOSの「システム設定」→「プライバシーとセキュリティ」→「リマインダー」で許可します。
- 同期中の表示が続く場合は、先の同期が完了してから再試行します。
- 更新では[ソースビルド手順](BUILD_FROM_SOURCE.ja.md)に従って再ビルドし、同じ拡張機能IDで生成したインストーラーを実行します。
